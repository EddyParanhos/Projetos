# Projetos — Edmar Paranhos

Fontes ADVPL autorais para estudo — rotinas genéricas (fiscal, cadastros, SPED).

| Fonte | Descrição |
|-------|-----------|
| `ExtMecf.prw` | Geração de arquivo Bloco M — LALUR/LACS (ECF) |
| `ExtT154Fat.prw` | Geração de TXT no layout TAF (títulos com retenção, eventos REINF) |
| `ImpTabErp.prw` | Importação genérica de CSV para cadastros (SF7, SFM, SB1, SB9, SA1, SA2) |
| `MATUCOMP.prw` | Alimentação de tabelas de complementos (SFX/CDG/CDT) — exemplo |
| `RefPisCfX.prw` | Atualização de valores PIS/COFINS (SFT) |
| `RetIcmBas.prw` | Exclusão do ICMS da base do PIS/COFINS + planilha de conferência |

Padrão: ADVPL, `RecLock`/`MsUnLock`, `ChangeQuery`, sem `SELECT *`.

> Nota: arquivos normalizados para UTF-8 para visualização no GitHub
> (originais em CP-1252, padrão TOTVS). Dados de exemplo são fictícios.
